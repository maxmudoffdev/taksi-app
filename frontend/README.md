# Taksi — frontend

React + TypeScript + Vite app for passengers, drivers, dispatchers and admins.
See the [main README](../README.md) for features, screenshots and setup.

```bash
npm run dev          # http://localhost:5173
npm run dev:lan      # phone on the same Wi-Fi (HTTPS)
npm run dev:tunnel   # phone on any network (Cloudflare Tunnel)
npm run build
```
